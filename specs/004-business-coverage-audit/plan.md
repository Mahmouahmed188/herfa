## Summary

Generate a complete gap analysis document (`docs/frontend-business-gap-analysis.md`)
that compares the current Herfa frontend implementation against all backend business
capabilities. The report catalogs every page, route, component, API integration,
React Query hook, form, dashboard, and role-based screen; maps each against the
corresponding backend module, entity, controller, DTO, endpoint, and business
workflow; produces an API coverage matrix; categorizes gaps by priority; and
generates a prioritized frontend roadmap.
