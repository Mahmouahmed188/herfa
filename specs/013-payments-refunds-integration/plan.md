## Summary

Complete the Payments & Refunds System by integrating frontend dashboards and history pages with the backend Payments and Refunds modules. This involves replacing mock data with real API calls, implementing status timelines, and ensuring seamless navigation between bookings, payments, and refunds.

## Technical Context

**Language/Version**: TypeScript 5.x / Next.js 14+ (App Router)

**Primary Dependencies**: TanStack Query (Server State), Zod (Validation), next-intl (I18n), Tailwind CSS (Styling), Radix UI (Primitives)

**Storage**: REST API (Backend: Payments & Refunds Modules)

**Testing**: Vitest (Unit/Integration), Playwright (E2E)

**Target Platform**: Web (Mobile, Tablet, Desktop) - WCAG 2.2 AA & RTL Support

**Project Type**: Web Application (Service Marketplace)

**Performance Goals**: Instant UI feedback via optimistic updates; <1s search/filter results

**Constraints**: <200ms p95 API response (target); Offline detection; RTL layout parity

**Scale/Scope**: 3 User Portals (Customer, Provider, Admin); Payments & Refunds lifecycle tracking

## Constitution Check
